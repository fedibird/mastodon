Fedibird Group protocol vocabulary v1

Machine-readable JSON-LD: https://fedibird.com/ns/group/v1 (application/ld+json) / v1.jsonld。この語彙のIRIは古い http://fedibird.com/ns# とは別の名前空間です。

#protocols — protocol set property

https://fedibird.com/ns/group/v1#protocols

Group Actorが自ら宣言する、対応するグループプロトコル方式IRIの集合です。JSON-LDの短縮キーは fedibirdGroupProtocols、型は @id、配列コンテナは @set です。特定ユーザーの投稿権限、所属、役職の証明にはなりません。

#MentionFollowAnnounce — Fedibird Group protocol v1

https://fedibird.com/ns/group/v1#MentionFollowAnnounce

ローカルFedibird Groupの公開方式: 成立済みFollowによるメンバーシップ、Groupへのmention、公開または未収載の投稿を要件とし、グループは元投稿URIを通常のAnnounceで再配送します。Announce(Create)ではありません。

このIRIはFEP-1b12、FEP-400e、FEP-5219への準拠や、リモートGroup・特定の閲覧者による投稿の許可を意味しません。実際の投稿可否はサーバー側認可が判断します。

ActivityPub Actorの例

{
  "@context": [
    "https://www.w3.org/ns/activitystreams",
    { "fedibirdGroupProtocols": {
        "@id": "https://fedibird.com/ns/group/v1#protocols",
        "@type": "@id",
        "@container": "@set"
    }}
  ],
  "type": "Group",
  "fedibirdGroupProtocols": [
    "https://fedibird.com/ns/group/v1#MentionFollowAnnounce"
  ]
}

上記は最小例であり、実際のActorにはid、inbox等の他フィールドも必要です。Actor側では拡張Contextをインラインで出力します。語彙定義へのリモートGETを受信時に強制する仕様ではありません。

変更方針

v1のIRIと意味は安定して維持します。非互換の仕様変更には新しいIRI・v2名前空間を使います。実装・レビュー: Issue #748 / PR #751。
